## ROOT CAUSE ANALYSIS

| Root Cause | Impact |
|------------|--------|
| Curriculum built from generic OSHA/ISO/NEBOSH base | Misses all Gulf-specific regulatory requirements |
| Unified-standards.ts has Gulf topics but modules.ts doesn't implement them | Knowledge exists in data layer but not in learning layer |
| No Gulf SME review during development | Cultural, environmental, legal gaps |
| No regional certification mapping | Learners can't achieve required certifications |
| No environmental/cultural adaptation | Heat, Ramadan, language, welfare ignored |
| No sector-specific Gulf content | Construction, O&G upstream/downstream missing |
